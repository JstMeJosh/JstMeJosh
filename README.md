## 🔨 Currently Building

**[RealTimeBoard](https://github.com/JstMeJosh/realtimeboardBackend)** — a real-time collaborative chat application.

- JWT-authenticated WebSocket connections, verified at the handshake before a connection is ever accepted
- Role-based board authorization (owner / moderator / member), with password-gated room joining
- Real-time messaging engine — send, edit, and soft-delete, with dual authorization (author or board admin) and room-scoped broadcasting via Socket.io
- Paginated message history with content sanitization for deleted messages

This is the first of three flagship projects in a structured portfolio program, each moving through backend → frontend → mobile before the next.
